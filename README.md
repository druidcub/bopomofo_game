# 注音小花園

給 5 歲孩子親子共玩的繁體中文網頁遊戲。原生 HTML/CSS/JavaScript，無第三方執行依賴、不需建置、不需登入。

## 啟動

在此資料夾的終端機執行：

```powershell
npm start
```

用瀏覽器開啟 http://127.0.0.1:4173 。也可以直接開 `index.html`；為了穩定的紀錄及瀏覽器行為，建議用本機伺服器。若 4173 已被使用，在 PowerShell 設定 `$env:PORT=4174` 再啟動。

## 內容

- 找找注音：8 個入門符號，家長可切換全部 37 個；每題 3 選 1。
- 聽聽找朋友：12 個生活字的開頭注音，使用裝置中文語音朗讀。
- 注音小火車：10 個兩符號音節的引導拼音，聲調預先放好。
- 每回合 5 題、答錯可重試、無倒數，完成後累積花朵。
- 設定及紀錄儲存於瀏覽器 localStorage；沒有後端、沒有資料上傳。
- 支援鍵盤 Tab / Enter、觸控、窄螢幕及減少動態效果設定。

語音需要裝置已有中文 TTS 聲音，品質可能因瀏覽器與系統而異；部分系統語音可能使用系統提供的網路服務。沒有中文聲音時改由大人讀題。尚未提供專業校音的符號音檔、筆順、聲調遊戲、錄音辨識或獨立拼音評量。

研究與設計見 `RESEARCH.md`。來源是設計依據，本遊戲尚未驗證教育成效。

## 驗證

```powershell
npm test
```

資料測試檢查 37 符號唯一性、注音拼法、開頭符號、題數、選項及題组限制。人工瀏覽器流程驗證三種模式、答錯重試、完成回合與手機版面。實際聽感仍須使用者在其裝置確認。
