# 注音小花園

給 5 歲孩子親子共玩的繁體中文網頁遊戲。60 個生活字、6 種玩法、3 首原創背景音樂。原生 HTML/CSS/JavaScript，無第三方執行依賴，不需建置或登入。

## 線上試玩

https://druidcub.github.io/bopomofo_game/

GitHub Pages 使用 main 分支根目錄發布；推送更新後自動部署。

## 本機啟動

```powershell
npm start
```

開啟 http://127.0.0.1:4173 。也可以直接開 `index.html`；建議用本機伺服器，以穩定保存紀錄。若 4173 已被使用，在 PowerShell 設定 `$env:PORT=4174` 再啟動。

## 玩法與題庫

- 找找注音：找相同字形，8 個入門符號或全部 37 個。
- 聽聽找朋友：聽生活字，找開頭注音。
- 注音小火車：照提示拼音，可選兩符號或兩、三符號題。
- 聲音尋寶：聽神祕詞語，選對應圖片；可展開大人讀題提示。
- 押韻好朋友：聽目標與選項，選聲韻部分相同的朋友。
- 注音翻翻卡：6 張卡片配成 3 對，可先看所有牌；配錯時自行蓋回重試。

題庫有動物、食物、大自然、生活物品各 12 字；身體、數字各 6 字，共 60 字。首頁主題用於聽詞、尋寶及拼音；某主題的合適拼音字不足 5 字時，會加入其他主題並標示。押韻題從全題庫選取，符號模式使用家長選定的符號範圍。

一般每回合 5 題，翻翻卡每回合 3 對；無倒數、無扣分、答錯可重試。花朵記錄參與，不代表精熟。設定和既有花朵紀錄儲存在 localStorage，升級保留舊紀錄。

## 聲音

`audio.js` 使用 Web Audio API 合成點選、翻牌、上車、成功、重試及完成音效；三首原創循環配樂：花園散步、星星搖籃、森林野餐。無第三方音樂素材或下載需求。

朗讀、音效、背景音樂分開控制；家長可以換曲、調音量並試聽。背景音樂預設關閉，點選後才能開始播放；朗讀時自動降低配樂音量，分頁隱藏時暫停。瀏覽器不支援音訊時仍可操作遊戲。

詞語朗讀需要裝置提供中文 TTS，品質因系統而異；部分語音可能使用系統網路服務。沒有中文語音時請大人讀題。尚未提供專業校音符號音檔、筆順、聲調遊戲、錄音辨識或獨立拼音評量。

## 驗證

```powershell
npm test
```

測試覆蓋題庫唯一性、注音拼法、六主題與兩難度的完整題組、押韻唯一答案、翻牌配對，以及音訊解鎖、獨立控制、朗讀降音量、切換分頁暫停恢復。另以瀏覽器驗證完整遊戲回合、重試、設定與窄螢幕。

支援鍵盤 Tab/Enter、觸控及減少動態效果偏好。研究與產品取捨見 `RESEARCH.md`，本遊戲尚未經親子試驗驗證教學成效。
