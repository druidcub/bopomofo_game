# 注音小花園

給 5 歲孩子親子共玩的繁體中文網頁遊戲。190 個生活字、590 個詞語與短語、19 種遊戲、3 首 CC0 音樂、5 首原創背景音樂。原生 HTML/CSS/JavaScript，無第三方執行依賴，不需建置或登入。

## 線上試玩

https://druidcub.github.io/bopomofo_game/

GitHub Pages 使用 main 分支根目錄發布；推送更新後自動部署。

首次連線開啟後，首頁會顯示是否已保存遊戲。保存完成後可離線開啟，配樂與音效由本機合成。部分裝置的中文朗讀需要網路，離線時可由大人讀題。瀏覽器清除網站資料後，需要再次連線保存。

提供網頁應用程式資訊與原創小兔圖示，支援的瀏覽器可透過選單加入主畫面。沒有自動安裝、推播或背景資料上傳。

## 本機啟動

```powershell
npm start
```

開啟 http://127.0.0.1:4173 。也可以直接開 index.html；建議用本機伺服器，以穩定保存紀錄。若 4173 已被使用，改設定 PORT 再啟動。

## 遊戲

| 玩法 | 操作與重點 |
| --- | --- |
| 找找注音 | 找相同字形。可用入門 8 符號、全部 37 符號或家長自選至少 3 符號。 |
| 聽聽找朋友 | 聽生活字，找開頭注音；開頭可能是聲母或介符。 |
| 注音小火車 | 聽詞語，從含干擾選項的注音中自由排車廂，按「出發」才檢查。點車廂取下；主動求助才提示一個位置。完整拼音只在答對後顯示。 |
| 聲音尋寶 | 聽單字或多字詞，選圖片。選項在同一主題，避免相同 emoji；可展開大人讀題提示。 |
| 押韻好朋友 | 聽目標與各選項，找聲韻部分相同、聲調可不同的詞。 |
| 注音翻翻卡 | 3、4、6 對卡片，可先看全部，配錯後自行蓋回。自選符號不足時減少對數。 |
| 同聲好朋友 | 比較詞語開頭，找相同開頭注音的朋友。 |
| 拍手小樂隊 | 聽 1～4 音節字詞，一字拍一下。用拍手按鈕記錄自己的節奏，再選拍數。 |
| 注音修理站 | 聽詞語，在兩或三符號的拼音中找回一個缺少的符號。 |
| 聲調滑滑梯 | 與大人一起聽詞、比手勢，選四聲路線。曲線是示意，不是實際語音測量。 |
| 花園大冒險 | 隨機走過五種玩法：找字形、尋寶、拍手、聽開頭、小火車或修理站。 |
| 注音花朵賓果 | 3／6／9 格找相同符號，集滿一排三個朋友；9 格也接受直排、斜排。 |
| 聲音小背包 | 聽 2 或 3 個詞，依序放入圖片卡。選項含兩張干擾卡；點位置可取下、自由重聽，裝好才檢查，求助只提示一個位置。 |
| 聲音郵差 | 點圖片信，再點開頭注音相同的家。可選 2 家／4 封或 3 家／6 封；每家提供另一個整詞例子朗讀，求助只提示一封信。 |
| 誰的開頭不一樣 | 聽三個生活字，兩個開頭相同、另一個不同；每張可重聽，也可一起聽。可在家長設定切換尾音比較：兩個詞押韻、另一個不同，忽略聲調。答對才完整說明三個詞的聲音。 |
| 詞語拼拼樂 | 親子進階活動。一塊積木是一個完整字音（含聲調），排列 2～4 字詞語，含兩塊干擾積木。相同音節有各自的積木可用。按完成才檢查，求助只提示一個位置。 |
| 聲音花圃 | 點圖片聽整詞、一字拍一下，再點對應拍數的花圃。預設 2 花圃／4 張圖，可選 3 花圃／6 張圖或 4 花圃／8 張圖；每個花圃兩個詞。自己拍、重拍、換圖片，錯誤不移動卡片；提示只陪聽一張。 |
| 聲音小天平 | 分別聽左、右兩個詞，一字拍一下；可自己記拍數、重拍，選左邊多、一樣多、右邊多。答對才顯示兩邊實際聲音數。求助只陪數左邊；家長可選最長 2／3／4 字。 |

一般回合 5 題，郵差送完 4 或 6 封信完成一回合。無倒數、無扣分，答錯可重試，不自動跳題。兩符號拼音為入門，兩或三符號為進階。八主題包含動物、食物、大自然、生活物品、身體、數字、動作、色彩。合適拼音字不足時加入其他主題並標示；同聲、押韻、郵差與開頭比較使用整座花園。最近 30 個玩過的詞優先避開，題庫較小時仍可能重複。冒險會另外排除當回合已出過的詞，即使整個主題都玩過，五站目標仍不重複。

首頁可按「看字形」「看圖與聽音」「和大人拼音」「聽音小任務」縮小玩法範圍，並隨時顯示全部。分類不是固定課程或解鎖條件。

## 探索與參與紀念

- 我的花園：選朋友，再點六個花圃自由布置；可選晴天、夕陽、星夜，完成回合逐步迎來 8 種裝飾。
- 聲音圖鑑：780 個字詞與短語分頁探索，可聽詞、看注音、按主題或玩過的詞篩選；中文字或注音搜尋會忽略空格與聲調。
- 圖鑑的多字詞可直接開始親子拼詞，該回合暫時配合所選詞長；不改寫家長的長期難度設定。
- 小兔幫我挑一個：從目前篩選範圍優先挑尚未玩過的詞；可直接邀請所選詞開始尋寶，不改動長期收藏偏好。
- 探險足跡：圖鑑內可看八個主題各遇過多少詞；這是參與紀錄，不是精熟比例。
- 喜歡的朋友：在圖鑑按愛心收藏最多 50 個詞；家長可選擇優先練習收藏，適合題目不足時仍會加入其他朋友。
- 小兔的邀請：完成回合後輪替推薦玩法，沒有每日或連續登入要求。
- 6 種徽章與花朵：依參與回合及玩法解鎖，不代表精熟程度。
- 家長可看已玩回合、接觸詞語數及最近詞語；不進行能力評分。

設定、花園與參與紀錄存於 localStorage；升級保留既有花朵、回合數。無帳號或後端上傳。清除紀錄前有明確確認。

一般模式避開近期詞語；收藏練習則可重複喜歡的詞。拍手題仍混合不同長度，混合冒險避免在同一回合重複同一個詞。字形遊戲使用自選符號，不受詞語收藏影響。

## 聲音

Web Audio API 合成點選、翻牌、上車、拍手、布置、成功、重試與完成音效。五首原創循環配樂：花園散步、星星搖籃、森林野餐、雨滴小圓舞、彩虹慢慢走。無第三方音樂素材。

朗讀、音效、配樂分開控制。音樂預設關閉，點選後開始，朗讀時自動放輕音量，分頁隱藏時暫停。家長可換曲、調音量與試聽；瀏覽器不支援音訊時仍可操作。

詞語朗讀依賴裝置中文 TTS，品質因系統而異，部分語音可能使用系統網路服務。無中文語音時請大人讀題。尚無教師校音錄音、筆順、錄音辨識或獨立拼音評量。題庫採字典本調，不出輕聲符號題；部分詞另有輕聲變讀，裝置朗讀可能不同。三聲曲線示意完整聲調，語流讀音可能不同。

## 驗證

```powershell
npm test
```

72 項測試涵蓋題庫唯一性與注音格式、八主題與兩難度的可解題組、押韻與同聲唯一答案、最近題目避重、混合冒險、翻牌難度、自選符號、小火車判定與單步提示、舊紀錄遷移、參與獎勵及音訊生命週期。新玩法另驗證每家恰好兩封且圖像互異、唯一不同開頭、收藏優先，以及搜尋、隨機探索與足跡計數。

新玩法測試涵蓋八主題、2～4 字難度、重複音節副本、干擾積木、五題不重複，以及每回合兩題左多、兩題右多與一題一樣多的比較。

另以瀏覽器操作完整回合、錯誤重試、提示、花園保存、圖鑑及手機版。支援 Tab/Enter、觸控與減少動態效果偏好。研究與產品取捨見 RESEARCH.md；本遊戲尚未經親子試驗驗證教學成效。

離線測試模擬斷網、資源更新與舊快取清理，檢查 GitHub Pages 子目錄範圍。更新不會自動重載正在玩的回合；有新版本時，家長小幫手提供更新按鈕。程式資源快取與花園紀錄分開，更新資源不清除花朵、收藏或花園。

三、四字題包括「小蝴蝶」「黑白熊貓」「香甜蘋果」等詞語或短語，用於聽詞與拍音節；字數不等於詞義單位數。拍手回合依長度先避開最近詞語，再混合 1～4 個聲音的題目。

聽音翻翻卡：2／3／4 對聲音與圖片卡。先看圖、點聲音卡聽完整詞，再配圖片；兩張聲音卡不算一對。配錯後自行蓋回，可重聽已配對卡片。提示只重讀一張；家長讀題只顯示已翻開的聲音卡。完成才領取一次參與花朵。

聽音翻卡的詞長可獨立選擇最長 2／3／4 字。圖鑑可以直接邀請選中的字詞開始聽音配對；所選詞較長時只暫時放寬當回合，不修改家長長期設定。

本輪增加 48 個場所、文具、樂器與水果詞，共 780 筆。六種新水果、口琴、木琴、白板與黑板補上原創 SVG。聲音花圃的每個拍數各有兩張不同圖片；不足的主題加入其他朋友並標示。每張種好才記詞語，完成整回合才領取一次花朵；提示不自動分類，也不公布拍數。

## 插畫花園（1.12.0）

「我的花園」改為原創 SVG 草地場景，有八個隱藏放置位置、花草／動物／裝飾工具箱。選朋友再點亮點即可放置；點已有朋友可聽名稱與注音、搬家、收回，並可復原最近一次布置。小花與小兔一開始即可選用，其餘朋友依參與回合解鎖；解鎖後可重複放置，不消耗花朵。

花草有生長動畫，小兔與青蛙跳入、蝴蝶飛入；配合既有音效開關，支援減少動態效果。晴天、夕陽、星夜會改變整個場景的色調。欣賞模式收起工具箱，顯示目前花草與動物數量，並可點朋友打招呼。遊戲結束解鎖的新朋友可直接帶回花園放置。

舊六格布置自動轉移到相對位置，花朵、回合、收藏與徽章保留。布置及三種布置紀念保存在本機；無法保存時會顯示提醒。

## 花園第 3 階段（1.13.0）

小花園、池塘與野餐角落各有八個放置位置，分開保存。新增 13 種 SVG 朋友與裝飾，共 21 種。池塘區的睡蓮與魚只出現水上位置，花草與長椅等使用岸邊位置；既有花園位置完整保留。可澆水、餵朋友與玩池塘波紋，沒有每日任務或枯萎機制。

拖曳工具箱朋友或已放好的朋友到場景亮點會自動吸附；放到場景外、沒有合適位置或取消操作時回原位。仍支援點選朋友再點位置，鍵盤可操作點選方式。

花園相簿保存區域、天氣與獨立的布置快照，最多 12 張；可還原布置、下載 1200×750 PNG、收起照片並復原最近收起的一張。照片只存在本機。

三首錄音採 CC0，可選單曲或電台輪播、切換下一首，朗讀時降低音量、離開頁面暫停。錄音與作者資訊皆存入離線快取；錄音載入失敗會退回原創合成配樂。完整作者、下載來源與授權見 [CREDITS.md](CREDITS.md)。
